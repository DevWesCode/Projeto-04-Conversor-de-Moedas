# 💱 Conversor de Moedas

Este projeto é um conversor de moedas que permite ao usuário converter valores entre diferentes moedas em tempo real, utilizando uma API pública de câmbio. O projeto foi desenvolvido com foco em consolidar os conhecimentos de **HTML**, **CSS** e **JavaScript**.


## 🔧 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- API: [AwesomeAPI - Economia](https://docs.awesomeapi.com.br/api-de-moedas)


## 🎯 Funcionalidades

- Selecionar a moeda de origem e destino (Dólar, Euro, Libra, Real, BitCoin).
- Inserir o valor a ser convertido.
- Visualizar os valores atualizados utilizando a taxa de câmbio atual atraves da API.
- Atualização dinâmica das bandeiras e nomes das moedas.
- Conversão pode ser ativada tanto pelo botão quanto pela tecla Enter.


## 🖼️ Layout

O layout foi pensado para dispositivos móveis e responsivo. Utiliza uma interface amigável com feedback visual imediato para cada ação do usuário.

- Imagem animada no topo para dar identidade visual.
- Seções separadas para entrada de dados e resultado da conversão.
- Ícones e bandeiras representando cada moeda.


## 🔍 Observações

- O projeto utiliza a API AwesomeAPI para obter as taxas de câmbio em tempo real.
- É necessário estar conectado à internet para o funcionamento da API.
- Os valores são formatados para o padrão brasileiro (ex: R$ 1.000,00).


## 🧠 Aprendizados

- Com este projeto, foi possível praticar:
- Manipulação do DOM com JavaScript puro.
- Consumo de APIs com fetch() e tratamento de Promise.
- Responsividade com CSS.
- Boas práticas na organização e estruturação do código front-end.
